Trình Trợ Giúp Kết Nối Modbus TCP Cho PLC

Trạm: SCALE_01 • IP: 192.168.1.100 • Port: 502

THÔNG SỐ KẾT NỐI (CONNECTION PARAMETERS) Chuẩn Quốc Tế RFC
Server IP: 192.168.1.100
TCP Port: 502
Unit / Slave ID: 1
Function Code: 03 (Read Holding)

// Hướng dẫn cấu hình khối lệnh MB_CLIENT trên TIA Portal:

1. Thêm khối lệnh MB_CLIENT trong TIA Portal (Communication -> Modbus TCP).

2. Khai báo tham số kết nối TCON_Config_IPv4:

InterfaceId = 64 (Cổng PROFINET)
ID = 1
ConnectionType = 11 (TCP)
ActiveEstablished = TRUE
RemoteAddress.ADDR = [IP CÂN]
RemotePort = 502

3. Tham số MB_CLIENT:

MB_MODE = 0 (Đọc dữ liệu)
MB_DATA_ADDR = 40003 (Đọc trực tiếp 32-bit Float Gross Weight)
MB_DATA_LEN = 2 (2 Words = 32-bit Real)
MB_DATA_PTR = P#DB1.DBX0.0 REAL (Địa chỉ Tag lưu khối lượng)

// Hướng dẫn cấu hình Modbus TCP trên GX Works 3 (FX5U):

1. Trong Ethernet Port Configuration -> Chọn Modbus/TCP Connection.

2. Lệnh đọc trong chương trình Ladder:

DMOVR K1 D100 (Channel 1)
S.CPRTCL [Channel] [Modbus Read Holding Registers]
Slave Address: 1
Start Address: 0x0002 (Tương ứng 40003)
Length: 2 Words

Mẹo: Trong phần cài đặt của cân, hãy bật tùy chọn "Word Swap" để số thực 32-bit khớp chuẩn Little-Endian của Mitsubishi!

// Hướng dẫn Delta DVP-SE / AS Series:

Sử dụng lệnh MODRW hoặc cấu hình trong Delta Data Exchange:

Remote Node IP = [IP CÂN] : 502
Read Function: FC03
Register: H0002 (Read Gross Weight Float)
Length: 2 Words -> Mapping vào D200 (Float)

// Thiết lập trên phần mềm Modscan32:

Connection: Remote Modbus TCP Server
IP Address: [IP CÂN]
TCP Port: 502
Point Type: 03: HOLDING REGISTER
Address: 0001 (hoặc 0003)
Length: 10
Display: Floating Point (Đọc được ngay số kg thực tế!)

Đầu cân: SCALE_01 (192.168.1.100)
